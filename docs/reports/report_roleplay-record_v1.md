## 本人が画面で確かめる手順
1. ターミナルで `npm run dev` を実行し、ブラウザで `http://localhost:5173` を開いてご自身の Microsoft 365 アカウントでログインします（初期状態は「テスト代表」）。
2. 左メニューの **「テーマ表」**（`#/themes`）を押し、画面上部に「卒業の候補」「確認のロープレ」「注意（14日以上練習中／1回30分超）」が件数つきで表示されること、課員ごとの練習中・卒業のテーマ一覧が表示されることを確かめます。
3. 左メニューの **「ロープレ」**（`#/roleplay`）を押し、課員を選ぶと「練習中のテーマ」「前回の宿題」「日付・実行者・時間帯」が自動で入ること、課員・内容・テーマ・時間帯がそろうと書きかけとして下書き保存されること、「今日直した点」「時間（分）」「合格ラインの○△×」を入れて「送る」を押すと記録が確定して一覧に並ぶこと（また「新しい言い方」を入力して送るとトーク一覧へ「確認待ち」で1件追加され、使ったトークにつながる）を確かめます。
4. 続けて、下の「役割を切り替えて確かめる手順」に沿って `npm run fixtures:dev-role` で役割を切り替え、画面を再読み込みして表示とボタンの出し分けを確かめます（最後に `npm run fixtures:dev-role -- ceo` で元に戻します）。

### 役割を切り替えて確かめる手順（2本とも終わったあとに本人が実行）
- **リーダー（`npm run fixtures:dev-role -- leader`）**：
  - 「ロープレ」画面で、課員の選ぶ欄に架空チームAの課員だけが出ること、自分が書いた書きかけの記録も一覧に出ること、「続きを書く」「直す」「消す」ができることを確かめます。
  - 「テーマ表」画面で、架空チームAの課員の行に「卒業にする」「練習中に戻す」「直す」「消す」ボタンが出ること、同じ内容（アポ／営業）で練習中のテーマがある課員には「テーマを足す」「練習中に戻す」ボタンが出ず理由が知らせの枠に出ること、**自分自身の行には操作ボタンが出ない**ことを確かめます。
- **メンバー（`npm run fixtures:dev-role -- member`）**：
  - 「ロープレ」画面で、同じチームAの人のロープレを実行者として書けること（ほかの人のテーマ表は読めないため、テーマ一覧から選ぶ形になること）、一覧には自分に送られた記録と自分が書いた記録だけが出ることを確かめます。
  - 「テーマ表」画面で、自分のテーマ表だけが見え、「テーマを足す」枠や「卒業にする」「練習中に戻す」などのボタンが一切出ないことを確かめます。
- **担当MGR（`npm run fixtures:dev-role -- mgr`）**：
  - 「ロープレ」画面で、担当している架空チームAの人だけが課員の選ぶ欄に出ること、一覧には担当チームの送った記録だけが出る（他人が書いた書きかけは見えない）ことを確かめます。
  - 「テーマ表」画面で、担当チームAのリーダー・メンバーのテーマを足す・卒業にする・練習中に戻すができることを確かめます。
- **代表に戻す（`npm run fixtures:dev-role -- ceo`）**：
  - 全チームの送った記録とテーマ表が見え、自分以外の全員に対してテーマの追加・卒業・練習中に戻すができることを確かめます。

   - 送った記録も書いた本人は直せるようにし、書きかけに戻す操作は出さないようにしました。
