一般日報のしくみ

明日の約束
本人が夜に決める、翌日のアポ・訪問・受注などの件数と、そのための打ち手。
翌日の業後に「約束 → 結果」として自動で並び、届かなければ要因を書く。
打ち手と狙い
打ち手は、目標に向けて具体的に何をするかを決めた行動。狙いは「こうすれば、こう変わるはず」という見込み。
「見込みに必ず日程を打診 → 見込みからのアポが増えるはず」のように1行で書く。責任者日報と同じ型。
上席
そのメンバーを担当する、上の立場の人。
メンバーにとってはリーダーと担当のMGR。日報を開くと「読んだ」が本人に見える。
日々のMVP
その日に最も良い稼働をしたメンバーを、責任者が1人選んだもの。数字だけでなく、稼働姿勢や周りへの良い影響も理由にする。
メンバーの日報の「良かった人」が、選ぶときの材料として並ぶ。
部下メモ
上席が部下に気づいたこと・指導したことの記録。本人には見せない。
仲間への指摘は日報ではなく、上席がここに書く。
Microsoft Forms
Microsoft 365 のアンケート作成の道具。回答はExcelに書き出せる。
今の一般日報はFormsで業後に送っている。
AIの本人版
メンバー本人に向けてAIが出す振り返りと提案。部下メモと責任者日報は渡さない。
一般日報・KPI・ロープレ・週間教育をもとに作る（まとまり3で決定）。

数字とほかの記録

電話システムのCSV
電話システムから書き出す、表の形の数字のファイル。
時間帯ごとの総・実・再・オ・見・アが入っている。業後に取り込む。
取り込みと承認
CSVの数字をアプリに入れ、管理者が件数やエラーを確かめて確定させること。
終業直後に1回行い、日報はそのあとに書く（まとまり4で決定）。
実率
かけた数（総）のうち、相手が出た数（実）の割合。
「実率 38%」は、100件かけて38件つながったということ。
ターム
1時間ごとの区切り。1タームに30コールが目安。
総が30件に届かなかった時間帯の数を、日報に自動で出す。
狙うリスト
週ごと・時間帯ごとに、どの業種・エリアのリストにかけるかを決めたもの。
日報の「明日のリスト」の最初の値になる。
見込みのランク
見込み（またかけるべき相手）を、確度でS・A・B・C・ランク無しに分けたもの。
今はメンバーが業後に別のExcelに入力している。アプリでの扱いは未決。
ロープレの記録
ロープレを行った側（実行者）が、1回1テーマで残す記録。合格ラインの○△×をつける。
受けたメンバーの日報の「今日のロープレ・研修」に自動で並ぶ。
研修の記録
複数人が参加する研修の記録。参加した本人も見られる。
参加した日の日報に自動で並び、本人は学んだことを1つ書く。
中央値
値を小さい順に並べたとき、ちょうど真ん中にくる値。極端に大きい値に引っぱられにくい。
