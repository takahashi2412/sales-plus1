SALES +1 ／ 開発体制

ルールは3層。共通は1か所に置き、役割は分けて、事故は仕組みで止める

2026年10月6日（火） ／ 頭脳＝Claude Code、手＝Antigravity の体制でのルールの置き方

結論

今のままでは、Antigravityにどの層のルールも届きません。共通ルールは1か所に置き、役割ごとのファイルを分け、事故につながるルールは仕組みで止めます。

1今：Antigravityは3層とも読まない

ルールは個人・Workspace・アプリの3層にあります。Claude Codeは3つとも読みますが、AntigravityはCLAUDE.mdを読みません。

個人層

~\.claude\CLAUDE.md

  • 日本語で回答する
  • 選択肢つきで確認する
  • 削除・pushの前に確認する
コマンドを実行するAntigravityにこそ必要なルールが届いていない

Antigravity × 読まない
Workspace層

C:\Workspace\CLAUDE.md

  • gitは自分から実行しない
  • 機密ファイルの置き場所
  • デザインシステムに従う
Claude Code ○ 読む
Antigravity × 読まない可能性が高い
アプリ層

apps\sales-plus1\CLAUDE.md

  • 実名データを置かない
  • 本人版に部下メモを渡さない
  • 命名・UIデザインのルール

Antigravity × 読まない

AntigravityでWorkspace層を「読まない可能性が高い」のは、apps\sales-plus1 を開いた場合、上の階層を読まないと考えられるためです（未確認）。

2改良案：正本は1か所、各ツールはそこを読む

正本は、ルールを書く唯一のファイルです。ルールを直すときは正本だけを直します。

Claude Code（頭脳）
正本（ルールを書く場所）
Antigravity（手）

個人層

日本語・確認のしかた・削除前の確認
Claude Code ~\.claude\CLAUDE.md 「このPCの役割」だけを書き、正本を @~/.gemini/GEMINI.md で読み込む
←
正本 ~\.gemini\GEMINI.md 2つのツールに共通の個人ルール
→
Antigravity 全体ルールとして、そのまま読む

Workspace層

フォルダ・機密・デザイン
Claude Code 今までどおり、そのまま読む
←
正本 C:\Workspace\CLAUDE.md Workspace全体のルール（変更なし）
→
例外：一部を書き写す アプリに関係する部分（機密・命名・デザイン）だけをアプリの AGENTS.md に入れる

アプリ層

apps\sales-plus1\
Claude Code CLAUDE.md 1行目の @AGENTS.md で正本を読み込む ＋頭脳役の仕事：設計・指示書づくり・レビュー
←
正本 AGENTS.md アプリの目的、守ること、命名、git方針、起動コマンド
→
Antigravity AGENTS.md をそのまま読む GEMINI.md ＋手の役の仕事：指示書に従う、決めずに質問、終わったら報告
ポイント

共通部分は正本に1回だけ書きます。役割の違い（頭脳と手）は、CLAUDE.md と GEMINI.md に分けて書きます。

3破ってはいけないことは、仕組みで止める

ルールファイルはAIへのお願いです。読み飛ばされると守られないので、事故につながるものはコードや設定で強制します。

守りたいことファイルだけだと仕組みで止める方法
本人版レポートに部下メモを渡さないAIが忘れると漏れるテストで自動確認し、通らなければ完成にしない
APIキーは .env に置くキーがコードに書き込まれる.gitignore（Gitに入れない一覧）に .env を入れる
実名データを置かない本物のデータを読み込まれる架空のサンプルデータを入れるファイルだけを用意する
赤は1画面1〜2か所画面ごとに色がばらつく色と余白をコードの1か所に部品として定義し、それ以外の色を使わない
削除・pushの前に確認自動で実行されるAntigravityの設定で、コマンドを自動実行しないようにする
ポイント

ルールファイルには「作業のやり方」を書きます。「破ってはいけないこと」は仕組みで止めます。

4作る前に確かめる3点

  1. 1
    AntigravityがAGENTS.mdを読むか
    確かめ方：Antigravityのバージョンが1.20.3以上かを見る
  2. 2
    上の階層のルールファイルを読むか
    確かめ方：Antigravityに「読み込んでいるルールファイルをすべて挙げて」と聞く
  3. 3
    日本語を含むパスで、@による読み込みが動くか
    確かめ方：Claude Code側で @~/.gemini/GEMINI.md を試す
