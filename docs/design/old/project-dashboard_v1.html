3AIの週次サイクル：計算はプログラム、解釈と提案はAI

AIには計算済みの数値だけを渡します。最後に決めるのは人です。

  1. 1プログラム
    集計・検知率、前週比、チーム平均との差、時間帯の落ち込みを計算
  2. 2AI
    原因の分析ロープレ・メモ・日報と突き合わせ、根拠つきで仮説を出す
  3. 3AI
    改善の提案今週の取り組みを、狙うKPI・期間・判定日つきで提案
  4. 4リーダー／MGR
    判断採用／修正して採用／却下 → 週間教育に登録
  5. 5プログラム＋AI
    効果の確かめ狙うKPIが動いたかを、チーム平均と比べて判定

5開発体制：考えるのはClaude Code、作るのはAntigravity

本線（main）は、あなたのOKのあとにだけ変わります。2つのツールは順番に使います。

  1. Claude Code① 計画ファイルを書くdocs/tasks/。ひな形の「守ること」を入れる
  2. Antigravity② 作業用ブランチで実装コミットまで。結果を docs/reports/ に残す
  3. Claude Code③ 差分をレビュー守りのテストが変わっていないか見る
  4. あなた④ OKを出すここを通らないと本線は変わらない
  5. Claude Code⑤ 取り込み・pushpushは毎回確認してから
