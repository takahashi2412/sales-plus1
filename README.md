# SALES +1（sales-plus1）

1DAY +1 ― 株式会社Rush up 営業部の管理アプリ（設計中・コードはまだない）

## 何をするアプリか
営業部でExcelに分かれて管理している6つの業務を1つにまとめ、メンバー1人ひとりを「カルテ」で一元把握する。
KPIはプログラムが集計し、AIが原因の仮説と「今週の+1」（改善の取り組み）を提案する。決めるのは人。

## 使う人
| 人 | できること |
|---|---|
| メンバー（20〜50人） | 業後に日報（採用・訪問件・受注と振り返り）を書く。自分のカルテ、チーム平均と順位、AI本人版を見る |
| リーダー（2〜3人） | 自チームのカルテを見る。部下メモ・ロープレ・責任者日報・週間教育を記録し、AIの提案を採用するか決める。未達の一覧を確認する |
| MGR（3人） | 担当チームについて、リーダーと同じ |
| 代表 | すべてを見る |
| 管理者（権限で与える） | KPIの取り込みと承認、名簿の修正、MGRの担当設定 |

ログインは会社のMicrosoft 365アカウント。PCとスマホの両方で使う。

## 6つの業務とデータの出どころ
| 業務 | 出どころ |
|---|---|
| 日々のKPI（総・実・再・オ・見・ア、時間帯14区分） | 電話システムのCSV。業後に1回取り込み、管理者が承認（いずれブラウザ自動操作で自動化） |
| 採用・訪問件・受注 | 一般日報で本人が入力（起きた日に数える） |
| 一般日報・責任者日報・部下メモ・ロープレメモ・週間教育 | アプリで入力 |

## 中心の考え方
- **カルテ**：1人を開くと、数字・推移・苦手な時間帯・指導の記録が1画面で見える
- **AIの週次サイクル**：集計（プログラム）→ 原因の分析と提案（AI）→ 判断（人）→ 取り組み → 効果の確かめ（チーム平均と比べる）
- **計算はプログラム、解釈はAI、決めるのは人**
- **部下メモと責任者日報は、メンバー本人に見せない**。AI本人版にも渡さない（コードで除外し、テストで確かめる）

## やらないこと
- KPIの手入力（電話システムから取り込む）
- 当日の途中のアラート（業後に、本人が立てた目標に届かなかった人の一覧をリーダーに出す）
- メンバー本人への未達の通知
- AIによる数値の計算
